# SparkStart Curated Knowledge Base

This directory contains curated, evidence-conscious references on task initiation, cognitive load reduction, executive functioning support, energy-paced pacing, and non-punitive recovery.

These documents are ingested by SparkStart's local RAG engine to ground task-sequencing recommendations in reputable psychological and educational methodologies.

## Disclaimer
SparkStart is a supportive productivity tool, not a medical device, diagnostic tool, or clinical intervention. It does not diagnose or treat ADHD, autism, anxiety, depression, or executive dysfunction. References are provided for educational scaffolding and task-structuring principles.
